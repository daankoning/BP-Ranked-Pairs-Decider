# BP Ranked Pairs Decider
Tool to help chairs decide triangular calls using the ranked pairs method as required by section 3.2 of the [WUDC Judging Manual](https://drive.google.com/file/d/1IvBju1RDN1WH_lK-8DxSsVFQuEurq0pN/view?usp=drive_link).

Tools implementing the Tideman method do already exist, but are not specialized to BP.
Consequently, they require inputs in a format not aligned with the way panels operate (namely vote totals for each ranking, rather than the margin on each pairwise comparison) and are overly general, requiring inputting each team every time.
Through specialization, this tool skips unnecessary steps in time-constrained deliberations.
